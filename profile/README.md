# Thesis Lab

我們為臺灣的碩博士生維護開源論文範本，也開發桌面論文編輯器 Thesis Lab。從封面、摘要到參考文獻，我們把各校常見的格式整理成可直接使用的範本，讓你把時間留給研究與寫作。

## 開源論文範本

依照你習慣的工具選一套。兩套範本都有可編譯的論文範例，選好學校、填入論文資料後，就能從範例開始修改。

- **Typst** 適合想用精簡語法撰寫並即時預覽的使用者。[查看 Typst 範本](https://github.com/Thesis-Lab-TW/tw-thesis-typ)
- **LaTeX** 適合已經在用 LaTeX 或 Overleaf 的使用者。[查看 LaTeX 範本](https://github.com/Thesis-Lab-TW/tw-thesis-tex)

送件前，請對照學校與系所最新的論文格式規定。

## Thesis Lab 桌面編輯器

如果你習慣用 Markdown，可以用 Thesis Lab 寫章節、插入公式與圖表、整理參考文獻，再套用學校版型輸出 PDF。寫作與排版可以在本機離線進行。[前往 Thesis Lab 官網](https://www.thesislab.app/)

## 一起維護範本

如果你發現版型和學校公告有出入，或想補上缺少的學校，歡迎到對應的範本回報。附上學校、系所和官方規範連結，能幫我們更快核對。[回報 Typst 範本問題](https://github.com/Thesis-Lab-TW/tw-thesis-typ/issues) · [回報 LaTeX 範本問題](https://github.com/Thesis-Lab-TW/tw-thesis-tex/issues)
